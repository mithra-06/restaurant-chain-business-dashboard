# restaurant-chain-business-dashboard
Restaurant sales analysis and interactive Power BI dashboard for branch performance, product sales, peak hours, and business insights.
## Restaurant Chain Business Dashboard

## Project Overview
This project analyses restaurant sales data using Microsoft Power BI to understand sales performance, popular products, peak business hours, and branch-level performance.

## Objectives
- Analyse total sales and product performance.
- Identify popular products and peak sales hours.
- Compare performance across restaurant branches.
- Explore daily revenue trends and seasonality where date data is available.
- Develop data-driven recommendations to improve sales and profitability.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- GitHub

## Dataset
The project uses restaurant sales data obtained from Kaggle. Dataset attribution and licence details will be added after verification.
